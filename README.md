🚗 GoCampus

GoCampus is a MERN Stack based college carpool platform that enables students to share rides safely with their classmates.
Drivers can publish rides, while students can search, request, and join available rides.

🌐 Live Demo: https://go-campus-weld.vercel.app

⚙️ Backend API: https://gocampus-backend.onrender.com

## ✨ Features

- 🔐 **Secure Authentication:** JWT-based login and registration with separate roles for Students and Drivers.

- 🚗 **Ride Publishing:** Drivers can create, manage, edit, and cancel rides by providing pickup location, destination, date, time, available seats, and fare.

- 🔍 **Smart Ride Search:** Students can search available rides using source, destination, and travel date filters.

- 🙋 **Ride Request System:** Students can send ride requests, while drivers can approve or reject them directly from their dashboard.

- 📊 **Role-Based Dashboards:** Separate dashboards for Students and Drivers with ride statistics, activity summaries, and profile management.

- 👥 **Passenger Management:** Drivers can view passengers, manage ride requests, and track completed rides.

- ☁️ **Cloud Deployment:** Frontend deployed on Vercel, backend deployed on Render, and data securely stored in MongoDB Atlas.
